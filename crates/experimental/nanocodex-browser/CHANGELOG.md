## [0.3.0](https://github.com/gakonst/nanocodex/releases/tag/v0.3.0) - 2026-07-26

### Changed

- Preserve the complete deterministic browser API as a standalone CDP
  controller and ordinary Nanocodex tool, with bounded diagnostics and
  replayable evidence.
- Consolidate the headed-browser VM composition into this experimental crate
  while leaving VM, network, image, and egress mechanics owned by
  `nanocodex-vm`.

## [0.1.1](https://github.com/gakonst/nanocodex/releases/tag/v0.1.1) - 2026-07-26

### Features

- Add typed, isolated Chromium automation for Code Mode
- Add deterministic browser contexts, semantic targets, and raw input
- Add replayable traces and bounded frontend diagnostics
- Add harness-owned authenticated state and network policy
- Add accessibility, PDF, Lighthouse, and CrUX audits
