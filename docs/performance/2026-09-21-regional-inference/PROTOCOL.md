# Regional inference benchmark, 2026-09-21

Three protected temporary Cloudflare Workers execute outbound inference measurements with placement hints `aws:us-east-1`, `aws:eu-west-1`, and `aws:ap-northeast-1`. Authenticated response `cf-placement` headers have confirmed IAD, LHR and NRT execution. The controller's SJC ingress is recorded separately and is not runner execution geography. Some individual response headers contain only `remote-`; these invocations have missing per-request execution evidence, even though the same deployed runner has corroborating named placement receipts. The production API response Ray suffix is API ingress, not provider compute location.

The production buffered baseline must finish before the production streaming deployment. Baseline and streaming matrices each contain 45 calls: three providers (Cloudflare, OpenRouter, Vercel), the identical `gpt-5.6-luna:low` candidate, three regional runners, and five repetitions. All request SSE, `store:false`, and at most 256 output tokens. Pair indices 0/2/4 use the short family; 1/3 use the same long synthetic prefix. Provider order rotates by repetition; regional controllers run concurrently and pace each key at least 7.5 seconds between starts. Matched stage comparisons retain exactly the same prompt identities, model, effort, family and runner. Changes in time, load and cache state remain before/after confounders.

`first_meaningful_ms` measures the runner's outbound POST to its first non-whitespace public text/tool argument delta. Headers, creation, reasoning and empty deltas do not count. JSON output is observable only after full parsing. The result records `buffering`; a buffered SSE replay is not incremental generation. These are API output delivery timings at the placed caller, not isolated provider generation timings. Controller-to-runner network time is excluded. Failed/incomplete calls remain in raw data and never count as zero-latency successes.

The first regional attempt failed synchronously on nine calls before receiving HTTP responses. Those rows remain in `baseline-failed-prefetch/`. `redirect:error` was replaced by Worker-compatible `redirect:manual`. A subsequent diagnostic received HTTP 404 before inference; enabling `global_fetch_strictly_public` allowed the runners to reach the production Worker. This behavior is documented in [Cloudflare Fetch](https://developers.cloudflare.com/workers/runtime-apis/fetch/). A successful US diagnostic then returned buffered Cloudflare Luna low output. Operational logs and private deployment paths are excluded from tracked results.

The initial budget is at most 200 total inference attempts and $5 incremental, including four earlier local successes, nine synchronous failures, one outcome-unknown interrupted diagnostic, the failed public-fetch diagnostic and the successful regional diagnostic. This is 16 attempts before the corrected 45-call baseline. Synchronous failures have no observed provider usage. Unknown outcomes remain conservatively counted. The three regional inference keys use distinct indices 0/1/2, each bounded to 100/day and 10/min. Local key index 8 is separate. No ambiguous failure is automatically retried. Runner authentication tokens and inference keys exist only in native private files and Worker secret bindings; no secrets appear in source or result files. Temporary runners expire and must be deleted after the campaign.

A controlled Jev comparison follows the streaming matrix. Calibration uses only pairs 0–2, pooled by provider and region with identical measurements supplied to both arms; heldout pairs 3–4 are excluded from calibration. An isolated benchmark deployment may invoke the actual production route resolver with either a trusted regional cohort or a null origin, retaining actual classifier call evidence, candidate probabilities, selected candidate, fallback reason and downstream measurements. The null arm must receive the same calibration dataset and differ only in origin context. Returned probabilities are classifier choice probabilities, never task success probabilities. If the classifier is bypassed, fails or falls back, record that result and do not claim a successful learned regional decision. The existing resolver bounds opening prompts, so the long family may deliberately bypass Jev; report this separately. API output delivery calibration is explicitly an experimental proxy, not a claim to production-internal TTFT instrumentation.

Nearest-rank quantiles use `ceil(p*n)`. Only five observations exist per provider/region, with two long and three short cases. Per-family p95 is effectively the maximum and cannot establish a robust population tail. Report completion rates, sample sizes, paired deltas and this limitation. Never pool unlike providers or prompt families into an unexplained headline. Repeated prefixes are opportunities for reuse, not evidence of cache hits; only positive provider-reported cached-token usage substantiates that claim. Missing cached-token fields mean unknown.

Run harness tests with `node --test scripts/regional-inference-bench/core.test.mjs`. `campaign.mjs baseline|streaming PRIVATE_RUNNERS_JSON OUTPUT_ROOT` refuses an existing stage directory and stops on failed/incomplete cases. `compare.mjs stage baseline streaming BEFORE_JSONL AFTER_JSONL` compares matched rows; negative after-minus-before deltas mean lower latency.
