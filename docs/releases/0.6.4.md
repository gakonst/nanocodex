# Nanocodex 0.6.4

Nanocodex and Nanocodex2 now provision OpenAI's actual CUA runtime automatically on macOS and Windows. The native installers refresh the upstream runtime, while direct binary installs provision it when the local computer integration starts. Both CLIs, local Hands, and the JavaScript desktop runtime discover the same per-user installation.

macOS downloads the official signed desktop app into a private cache. Windows installs the official Microsoft Store package and verifies a private copy of its CUA runtime and matching native hosts. The ChatGPT GUI does not need to be running. Use `nanocodex2 computer setup --refresh` to update or repair the runtime. Explicit `NANOCODEX_COMPUTER` settings, including `off`, remain supported.

This release also incorporates the merged Codex prompt, shared tool contract, Code Mode, web tool, compaction, and memory API alignment. Nanocodex's production Code Mode remains QuickJS.

Linux retains its existing computer backend; no official Linux Sky distribution is provisioned. Installing the upstream provider does not grant OS permissions or provider consent. Desktop and remote-Hand approval-form UI remains separate work, so operations requiring an unwired approval form remain unavailable.

The unpublished 0.6.2 and 0.6.3 candidates were superseded during validation. This release corrects the pinned CDN example and preserves QuickJS helper bindings through production minification, with regression tests against actual minified bundles.
