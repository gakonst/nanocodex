# Nanocodex 0.6.5: one-command account, CUA, and Hand setup

Nanocodex setup is now one native, idempotent journey on macOS, Linux, and Windows. The public bootstrap downloads one checksum-verified platform entrypoint; Rust installs the matching `nanocodex` and `nanocodex2` binaries, signs in to the Nanocodex account by phone and SMS, provisions the platform's Computer Use runtime, installs and starts the local Hand, verifies that its screen is reachable, and prompts for the browser extension when it is missing.

The installer no longer downloads the whole upstream Codex desktop distribution. On macOS it discovers the official OpenAI release and range-downloads only the signed headless CUA and browser components. Generated browser-bridge configuration stays in mutable Nanocodex state, leaving the verified upstream bundle unchanged across setup reruns. Windows installs and verifies the official platform runtime. Linux and screen-only Hands, including VMs and Cloudflare Sandboxes, expose the native screen action contract when an upstream CUA provider is unavailable, so `cua_repl` no longer rejects them merely for being screen-only.

Hand lifecycle commands now share one contract across a macOS LaunchAgent, Linux systemd user service, and Windows per-user Task Scheduler job. `nanocodex hand install --target user@host [--port PORT]` retains remote Linux enrollment: the controller sends its existing account enrollment over private standard input, and the remote machine does not perform interactive authentication. Re-running local setup repairs the installation while preserving the account, Hand identity, workspace, and explicit updater choices.

Verified updates are transactional and use native hourly schedules on every desktop platform. The POSIX bootstrap also resolves the current stable release before handing control to Rust, preventing a newly deployed installer from invoking commands that the latest published binary does not yet understand.

## Install

macOS and Linux:

```sh
curl -fsSL https://nanocodex.paradigm.xyz | bash
```

Windows PowerShell:

```powershell
irm https://nanocodex.paradigm.xyz/install.ps1 | iex
```

Existing installations can run `nanocodex update`, followed by `nanocodex setup` to repair or complete account, CUA, Hand, and extension setup. Release assets are covered by `SHA256SUMS`.
