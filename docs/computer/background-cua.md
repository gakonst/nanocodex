# Background computer use

Nanocodex delegates computer use to the installed official OpenAI Sky MCP provider.
The former independent CUA runtime, Hyprland input plugin, custom cursors, and
background-loop examples have been removed. Their historical benchmarks do not
establish the behavior of the upstream provider.

Use the installed provider’s returned API documentation for native window and
browser control. Background input, cursor behavior, permissions, and supported
platforms are determined by that provider.

See [installation and platform support](upstream-provider.md).
