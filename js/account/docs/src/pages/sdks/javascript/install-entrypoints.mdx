# Install TypeScript and JavaScript

Install the core package for Node.js 22.13 or newer, browser Workers, or a
server isolate:

```sh
npm install nanocodex
```

Import from the host you actually run:

```js
import { Agent, Actions, Transport, Workspace } from "nanocodex/node";
```

```js
import { Agent, Subagents, Transport, Workspace } from "nanocodex/browser";
```

`nanocodex/browser` owns a module Worker and accepts only structured-clone-safe
configuration. For a caller-owned browser Worker, Cloudflare Worker, Vercel
Function, or another Web API isolate with function-valued tools, sockets, or
durability, import the current-isolate host:

```js
import { Agent, Subagents, Transport } from "nanocodex/host";
import { createMemoryDurabilityStore } from "nanocodex/durability";
```

All three entrypoints expose the same Rust-owned session behavior and
`Agent.create(...)` shape. Host-specific exports supply socket and workspace
adapters; generated wasm-bindgen handles remain package internals.

## Know what is published

The registry package contains the core root, Node, browser, host, durability,
and WASM entrypoints.
The intentionally narrow React Context/hooks and artifact companion packages
currently ship from repository source. Pin a repository revision when adopting
a source-distributed package so its bindings and generated WASM stay coherent.
UI frameworks and terminal renderers consume Agent events directly and remain
application code.

The package Vite plugin generates WASM and configures both the page and nested
Worker graphs:

```js
import { nanocodex } from "nanocodex-vite";
import { defineConfig } from "vite";

export default defineConfig({
  plugins: [nanocodex()],
  worker: { format: "es" },
});
```

This keeps the browser shell's SSH compatibility boundary consistent without
adding another agent runtime.
